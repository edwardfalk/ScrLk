# Assets

- Place your avatar images here.
- Default environment variables (overridable):
  - AVATAR_IDLE=assets/avatar_idle.png
  - AVATAR_TALK=assets/avatar_talk.png

Guidelines:
- Prefer PNG with transparent background or pure black (#000000) backdrop.
- Use same resolution/aspect for both images for clean toggling.
- Speaking animation toggles between TALK and IDLE at AVATAR_FPS (default 8 fps).
